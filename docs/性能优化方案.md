# 监控系统性能优化方案

## 📋 概述

本文档详细分析了监控系统在大量节点情况下的性能瓶颈，并提供了完整的优化方案。当前系统在处理1000+节点时存在严重的性能问题，需要进行系统性的优化。

## 🚨 当前性能瓶颈分析

### 1. 告警评估性能瓶颈

#### 问题描述
当前告警评估流程存在严重的性能问题：

```cpp
// AlertingOrchestratorService::runChecks()
for (const auto& node : allNodes) {           // O(N) - N个节点
    checkNodeAlerts(node);
}

// AlertingOrchestratorService::checkNodeAlerts()
for (const auto& rule : activeRules) {        // O(R) - R个规则
    checkRuleForNode(rule, node);
}

// AlertingOrchestratorService::checkRuleForNode()
auto recentMetrics = metricRepository_->findRecent(nodeId, minDuration); // O(M) - M条指标数据
```

**总体时间复杂度：O(N × R × M)**
- N = 节点数量（如1000个节点）
- R = 告警规则数量（如50个规则）
- M = 每个节点的指标数据量（如最近1分钟的数据）

#### 性能问题
1. **重复查询指标数据**：每个规则都会调用 `findRecent()` 查询相同节点的相同时间段数据
2. **线性搜索效率低**：`MockMetricRepository::findRecent()` 使用线性搜索
3. **重复的告警事件查询**：每个规则都会查询是否已存在活跃告警

#### 性能计算
- 1000个节点 × 50个规则 = 50,000次数据库查询
- 每次查询需要遍历所有指标数据
- 告警检查间隔30秒，但每次检查需要数分钟完成

### 3. 性能瓶颈量化

#### 理论性能计算
假设场景：**1000个节点，每10秒上报一次**

| 操作 | 频率 | 时间复杂度 | 瓶颈 |
|------|------|------------|------|
| 心跳接收 | 1000次/10秒 | O(1) | HTTP线程池 |
| 资源接收 | 1000次/10秒 | O(1) | HTTP线程池 |
| 节点查询 | 1000次/10秒 | O(N) | 线性搜索 |
| 指标保存 | 1000次/10秒 | O(1) | 锁竞争 |
| 告警评估 | 1000×50次/30秒 | O(N×R×M) | 大量循环 |

**总QPS：200 QPS（心跳+资源）**

#### 实际瓶颈点
1. **HTTP线程池限制**：httplib默认线程池大小有限
2. **内存锁竞争**：所有操作共享一个mutex
3. **线性搜索效率**：节点查询O(N)，指标查询O(M)
4. **内存管理开销**：频繁的内存分配和自动清理

#### 1.2 索引优化
```cpp
class IndexedMetricRepository {
private:
    // 按节点ID建立索引
    std::map<std::string, std::vector<MetricSnapshot>> nodeIndex_;
    
    // 按时间戳建立索引
    std::map<uint64_t, std::vector<MetricSnapshot*>> timeIndex_;
    
public:
    std::vector<MetricSnapshot> findRecentOptimized(
        const std::string& nodeId, 
        int32_t recentSeconds
    ) {
        // O(log N) + O(M) 而不是 O(Total)
        auto it = nodeIndex_.find(nodeId);
        if (it == nodeIndex_.end()) return {};
        
        // 二分查找时间范围
        uint64_t cutoffTime = getCurrentTime() - recentSeconds;
        auto& snapshots = it->second;
        
        auto start = std::lower_bound(snapshots.begin(), snapshots.end(), 
                                    cutoffTime, 
                                    [](const MetricSnapshot& s, uint64_t time) {
                                        return s.getTimestamp() < time;
                                    });
        
        return std::vector<MetricSnapshot>(start, snapshots.end());
    }
};
```

**优化效果：**
- 查询时间复杂度：O(log M) 替代 O(M)
- 性能提升：50-100倍

#### 1.4 并发处理
```cpp
class ConcurrentAlertingService {
public:
    void runChecksConcurrent() {
        // 使用线程池并发处理节点
        std::vector<std::future<void>> futures;
        
        for (const auto& node : allNodes) {
            futures.push_back(
                threadPool_.enqueue([this, node]() {
                    checkNodeAlerts(node);
                })
            );
        }
        
        // 等待所有任务完成
        for (auto& future : futures) {
            future.wait();
        }
    }
};
```

**优化效果：**
- 时间复杂度：O((N × R × M) / P) 其中P = 线程数
- 性能提升：P倍（线程数）

```cpp
class BatchIngestionService {
private:
    std::queue<HeartbeatRequestDTO> heartbeatQueue_;
    std::queue<ResourceReportRequestDTO> resourceQueue_;
    std::mutex heartbeatMutex_;
    std::mutex resourceMutex_;
    static constexpr size_t BATCH_SIZE = 100;
    
public:
    void processHeartbeatAsync(const std::string& body) {
        auto dto = SimpleJsonParser::parseHeartbeatRequest(body);
        
        {
            std::lock_guard<std::mutex> lock(heartbeatMutex_);
            heartbeatQueue_.push(dto);
        }
        
        // 批量处理
        if (heartbeatQueue_.size() >= BATCH_SIZE) {
            processBatchHeartbeats();
        }
    }
    
    void processBatchHeartbeats() {
        std::vector<HeartbeatRequestDTO> batch;
        {
            std::lock_guard<std::mutex> lock(heartbeatMutex_);
            while (!heartbeatQueue_.empty() && batch.size() < BATCH_SIZE) {
                batch.push_back(heartbeatQueue_.front());
                heartbeatQueue_.pop();
            }
        }
        
        // 批量转换和保存
        std::vector<domain::ServerNode> nodes;
        for (const auto& dto : batch) {
            nodes.push_back(DTOConverter::toServerNode(dto));
        }
        
        nodeRepository_->saveBatch(nodes);
    }
};
```

### 4. 存储优化

#### 4.1 索引优化
```cpp
class IndexedNodeRepository {
private:
    std::map<std::string, std::unique_ptr<domain::ServerNode>> nodes_;
    std::map<std::string, std::string> ipToNodeIdIndex_;  // IP -> NodeID 索引
    std::shared_mutex nodesMutex_;  // 读写锁
    
public:
    std::vector<domain::ServerNode> findByIpAddress(const std::string& ipAddress) {
        std::shared_lock<std::shared_mutex> lock(nodesMutex_);
        
        // O(log N) 而不是 O(N)
        auto it = ipToNodeIdIndex_.find(ipAddress);
        if (it != ipToNodeIdIndex_.end()) {
            auto nodeIt = nodes_.find(it->second);
            if (nodeIt != nodes_.end()) {
                return {*(nodeIt->second)};
            }
        }
        return {};
    }
    
    void save(const domain::ServerNode& node) {
        std::unique_lock<std::shared_mutex> lock(nodesMutex_);
        
        // 更新索引
        ipToNodeIdIndex_[node.getIpAddress()] = node.getNodeId();
        nodes_[node.getNodeId()] = std::make_unique<domain::ServerNode>(node);
    }
};
```

**优化效果：**
- 查询时间复杂度：O(log N) 替代 O(N)
- 性能提升：100-1000倍

```cpp
class MultiLevelCache {
private:
    // L1缓存：内存缓存
    std::unordered_map<std::string, CachedData> l1Cache_;
    std::mutex l1Mutex_;
    
    // L2缓存：Redis缓存
    std::unique_ptr<RedisClient> redisClient_;
    
public:
    std::optional<MetricSnapshot> getLatestMetric(const std::string& nodeId) {
        // L1缓存查找
        {
            std::lock_guard<std::mutex> lock(l1Mutex_);
            auto it = l1Cache_.find(nodeId);
            if (it != l1Cache_.end() && !it->second.isExpired()) {
                return it->second.data;
            }
        }
        
        // L2缓存查找
        auto redisData = redisClient_->get("metric:" + nodeId);
        if (redisData) {
            // 更新L1缓存
            updateL1Cache(nodeId, *redisData);
            return *redisData;
        }
        
        // 数据库查找
        auto dbData = metricRepository_->findLatest(nodeId);
        if (dbData) {
            // 更新缓存
            updateL1Cache(nodeId, *dbData);
            redisClient_->set("metric:" + nodeId, *dbData, 60); // 60秒过期
        }
        
        return dbData;
    }
};
```

**优化效果：**
- 查询延迟：从10ms减少到0.1ms

```cpp
        HeartbeatResponseDTO response;
        response.code = 0;
        response.message = "accepted";
        
        // 异步处理
        batchProcessor_.addHeartbeat(dto);
        
        return response;
    }

    class BatchProcessor {
        void processBatch() {
            auto batch = getBatch();
            std::vector<domain::ServerNode> nodes;
            for (const auto& dto : batch) {
                nodes.push_back(DTOConverter::toServerNode(dto));
            }
            nodeRepository_->saveBatch(nodes);
        }
    };
};
```
